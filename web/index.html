What is Arctic Shift?

Arctic Shift (arctic-shift.photon-reddit.com) is a community project that hosts archived public Reddit data with a free HTTP search API. This app uses it as the default source because Reddit’s live site often blocks unauthenticated JSON scrapers.

Is the official Reddit API free?

  • Yes, with limits. You create an app at reddit.com/prefs/apps, get a client id/secret, and call OAuth endpoints free for modest non-commercial use.
  • Free tier is rate-limited; commercial / high-volume use may need Reddit’s paid Data API terms.
  • Unauthenticated reddit.com/*.json scraping is unreliable (often 403) and against spirit of the rules — prefer OAuth or an archive like Arctic Shift.

Privacy / compliance

  • Read-only. No voting, posting, or messaging.
  • Your LLM API key never leaves the browser except to the base URL you set.
  • Respect Reddit and Arctic Shift rate limits; don’t bulk-redistribute corpora.
