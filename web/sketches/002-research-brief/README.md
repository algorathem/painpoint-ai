# Variant: Research Brief (light, editorial)

## Design stance
A calm, narrative report — like an analyst memo or newsletter. Leads with a
single insight, then walks the reader through angles, ranking, sentiment, and
market value as prose with supporting visuals.

## Key choices
- Layout: single narrow column, serif headlines, generous whitespace
- Typography: Source Serif 4 for headings/lede, Inter for UI
- Color: warm paper background, deep green accent, amber for WTP-mid
- Interaction: minimal (no table), quote callouts with source links

## Feature coverage (the ask)
- Problem summary (lede + per-brief "problem" paragraphs) ✓
- Startup angles (numbered briefs) ✓
- Pain ranking (list with severity bars) ✓
- Sentiment analysis (donut + note) ✓
- Expected market value (SAM bars) ✓
- WTP vs frustration (explicit split, in prose + badges) ✓

## Trade-offs
- Strong at: readability, narrative, persuasion, stakeholder sharing
- Weak at: rapid comparison across many ideas, density, mobile density
- Best shared as a PDF/print or a link, not a work surface

## Best for
Sharing findings with a co-founder, investor, or non-technical reader who
needs the story, not the raw data.
